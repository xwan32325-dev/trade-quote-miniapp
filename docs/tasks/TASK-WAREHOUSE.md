# 本次任务：新增「仓储费」独立输入（默认 0），并把「目的地费用」默认改为 0

## 背景

用户反馈：
1. 目前没有单独的**仓储/仓库费**字段 —— 国内费用是个大项（报关/拖车/单证/银行），很多业务员不会把仓储算进去，导致成本少算
2. 原则：**没有这项支出就应该默认 0**，填了才计入

## 一、新增输入（成本与费率卡片）

- 字段名：`仓储费（仓库/装柜，整票）`，单位 `¥`，**默认 0**，`type="digit"`
- 变量名 `form.warehouseFee`
- 紧跟「国内费用合计」之后
- 同时把「国内费用合计」的标签/提示改成明确不含仓储：`国内费用合计（报关/拖车/单证/银行，不含仓储费）`

## 二、计算口径

```
货值成本¥   = (采购含税价 - 退税额/件) × 数量
EXW 成本¥   = 货值成本¥                                   ← 不含国内费用与仓储费
其他术语成本¥ = 货值成本¥ + 国内费用 + 仓储费              ← 新增仓储费
之后按原口径加 运费 / 保险 / 目的地费用 / 关税 / 进口增值税
```

- 仓储费与国内费用同级，**所有非 EXW 术语都要计入**（含 FOB/FCA/CPT/CIP/DAP/DPU/DDP）
- 出口总成本（¥，用于换汇成本与盈亏率）= 货值成本 + 国内费用 + 仓储费
- 手动定价模式下的「成本基准」同样要包含仓储费（因为它走 `calcTermQuote({...input, profitRate:0})`，只要把字段接进 input 即可）

## 三、另一处默认值调整

「目的地费用（整票）」默认值 **800 → 0**（没有这项支出时不该凭空多出成本），其余默认值不变。

## 四、展示

1. 「报价结果」区：当 `仓储费 > 0` 时，在成本明细里加一行 `仓储费   ¥ 1,200.00`（放在「出口成本」之后、运费之前）
2. 复制报价文本不需要单列仓储费（属内部成本），保持现有格式
3. `form.warehouseFee` 参与表单记忆
