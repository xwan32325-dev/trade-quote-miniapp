# 本次任务：术语单价改为「可手动填写」，并反算利润/盈亏

## 背景

现在报价结果里的 `XX 单价 / XX 总价` 是按成本加成**算出来的**（不是固定值），业务员只能改成本去逼近目标价。
但外贸实际经常反过来：**先定卖价**（客户压价、对标市场价），再看利润够不够。
所以单价要能直接填，填了之后反算利润、盈亏率、换汇成本。

## 一、交互设计

1. 报价结果区的 `XX 单价` 一行，改成**可编辑输入框**：
   - 默认显示按成本算出的值（保留 2 位小数）
   - 用户一改 → 进入 **手动定价** 状态，行尾出现小标记 `手动` 和按钮 `恢复按成本计算`
   - 点「恢复按成本计算」→ 清空手动价，回到按成本计算
2. 手动定价时：
   - `XX 总价 = 手动单价 × 数量`
   - 「预期利润率」输入框后面标灰小字 `（手动定价时不生效）`
   - 反算并显示：**成本加成率**、**盈亏率**、**换汇成本**；低于成本要显红并提示「低于成本 X」
3. 手动价参与**表单记忆**（记住手动价，下次打开还在手动状态）；切换术语/币种时**清空手动价**回到计算值（避免口径错乱）

## 二、反算口径（严格照抄）

记：Q=数量、X=汇率、I=保险费率%、M=投保加成%、T=关税%、IV=目的国增值税%、U=手动单价(外币/件)

```
手动总价 T$        = U × Q
成本基准 U0$       = 把利润率临时置 0，用同一套 calcTermQuote 算出该术语的单价
成本基准 C$        = U0$ × Q
利润额$            = T$ - C$
成本加成率%        = 利润额$ / C$ × 100        // C$ 为 0 时返回 0
```

**FOB 净收入**（用于换汇成本/盈亏率，按术语把附加费用扣掉，注意方向）：

```
附加费用$ = 该术语相对 FOB 多出来的部分：
  FAS / FOB / FCA       → 0
  CFR / CPT             → 运费
  CIF / CIP             → 运费 + 保险费
  DAP / DPU             → 运费 + 目的地费用
  DDP                   → 运费 + 目的地费用 + 进口关税 + 进口增值税
  EXW                   → 0 - 国内费用/X      （EXW 不含国内费用，倒推 FOB 要加回来）
FOB 净收入$ = T$ - 附加费用$
换汇成本    = 出口总成本¥(含国内费用) / FOB 净收入$      // FOB 净收入为 0 时返回 0
盈亏率%     = (FOB 净收入$ × X - 出口总成本¥) / 出口总成本¥ × 100
```

- 保险费/关税/进口增值税在手动模式下仍按**现有公式**算（保险按 T$ 计：`保险$ = T$ × I/100 × (1+M/100)`；
  DDP 的关税/进口增值税基数 = 该术语的到岸价口径，沿用 `calcTermQuote` 里已算好的值）
- 所有结果不得出现 NaN / Infinity

## 三、展示

```
报价结果
  贸易术语            DDP（完税后交货）
  DDP 单价            [ 19.02 ] $ / 件    手动  恢复按成本计算   ← 输入框
  DDP 总价            $ 19,019.03
  ─────────────────────────────
  出口成本（含国内费用）  ¥ 90,495.58
  运费 / 目的地费用 / 进口关税 / 进口增值税   （照旧按术语显示）
  成本加成率           10.00%              ← 手动模式下替代「利润率」
  换汇成本（按 FOB 口径） 6.0951 盈利
  盈亏率               10.00%
  未计入本术语：保险费
```

- 手动价低于成本时：单价/总价与「成本加成率」显示**红色**，并加一行红字 `低于成本 $ 1,234.56`
- 非手动时保持现状（按成本计算）

## 四、复制报价文本

手动定价时，金额与术语行照旧用**手动价**；额外加一行 `定价方式：手动定价（成本加成率 8.30%）`。

## 五、约束

- 不改现有 `calcTermQuote` 的计算逻辑（只新增一个"利润率置 0"的调用来求成本基准）
- **不要启动任何服务**（8787 / 8790 / 5173 在跑，5174 可能也在），**不要**跑 `dev:mp-weixin`
- 自测：
  1. Node 断言：手动价 = 成本价时，成本加成率 = 0、盈亏率与按成本计算一致；手动价 = 成本价 × 1.2 时成本加成率 ≈ 20%；手动价低于成本时利润额为负；Q=0 / 汇率=0 时不出现 NaN
  2. `npm run build:mp-weixin` 与 `npm run build:h5` 都要 Build complete
- 提交：`git -c user.email=dev@local -c user.name=dev commit -m "feat(quote): 术语单价支持手动填写并反算利润/盈亏"`
