# 本次任务：记录页加「日期查询」，入口做成贴边悬浮球

## 需求

记录攒多了不好找，要能**按日期查**。入口不要占地方：做成一个**半藏在屏幕边缘的悬浮球**，点开才展开筛选面板。

## 一、悬浮球（记录页 `src/pages/history/index.vue`）

- 位置：屏幕右侧偏下，**默认贴边半藏**（约有一小半在屏幕外，如 `right: -20rpx`），半透明（`opacity: 0.7`），不挡内容
- 大小约 `96rpx` 圆球，球内文字：**筛选**（两字，字号小些，竖排或横排均可）
- **可上下拖动**（用 `movable-area` + `movable-view`，H5 与小程序都支持），松手后吸附到最近的左/右边缘（或就停在右侧），**位置记忆到本地存储**（key 如 `history:ball`，存 y 值）
- **点击（非拖动）→ 展开日期筛选面板**；拖动距离超过阈值（如 8px）就不算点击
- **当前有筛选生效时，球上显示一个小圆点**（提醒"筛选开着"，避免用户以为记录丢了）
- 展开面板时球可以隐藏或变暗

## 二、日期筛选面板（底部弹层，自己写样式，别引 UI 库）

1. 标题「按日期筛选」+ 右上角关闭
2. **快捷选项**（chips，单选）：`今天`、`近 7 天`、`近 30 天`、`本月`、`全部`
3. **自定义范围**：开始日期 / 结束日期，各用 `<picker mode="date">`，选中后快捷选项自动取消选中
   - 起止颠倒时自动交换（如开始 > 结束）
4. 底部两个按钮：`确定`、`重置`（重置 = 回到「全部」）
5. 面板顶部显示一句话说明当前范围与条数，例如：
   `2026-10-01 ~ 2026-10-05 · 共 3 条`

## 三、列表过滤

- 按 `item.createdAt` 过滤，**含首尾当天**（当天按 `00:00:00 ~ 23:59:59` 处理）
- 列表顶部（「清空全部」那一行）显示当前筛选状态：
  - 无筛选：`共 N 条记录`
  - 有筛选：`共 N 条记录 · 筛选：最近 7 天`（或自定义范围文案）+ 一个 `清除筛选` 文字按钮
- 筛选后没有记录：空状态显示「该时间段没有记录」+ `清除筛选` 按钮（不要显示"还没有保存的报价记录"，会让人以为记录丢了）
- **「清空全部」仍然清空所有记录**（不是只清筛选结果），但确认弹窗文案要把两者都说明白：
  `将删除全部 12 条记录（当前筛选出 3 条），删除后不可恢复`

## 四、记忆

- 筛选条件（快捷选项 id 或自定义起止日期）存本地（key 如 `history:filter`），下次进入记录页保持
- 悬浮球 y 位置存本地（key 如 `history:ball`）

## 五、约束

- 不引 UI 库；不改报价/计算相关逻辑
- 只改 `src/pages/history/index.vue`（如需公共工具可加在 `src/utils/`）
- **不要启动任何服务**（8787 / 8790 在跑），**不要**跑 `dev:mp-weixin`，**不要删 `dist` 目录**
- 自测：`npm run build:mp-weixin` 与 `npm run build:h5` 都要 Build complete
- 提交：`git -c user.email=dev@local -c user.name=dev commit -m "feat(history): 日期筛选（贴边悬浮球入口）"`
